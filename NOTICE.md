# Notice

LeoTube is a native Cocoa/AppKit client concept for Mac OS X 10.5.8 Leopard PowerPC.

This repository contains FreeTube source code under `vendor/FreeTube/` as an unmodified reference snapshot.

FreeTube is not used as the technical base for LeoTube. It is kept as a functional blueprint only.

The FreeTube license remains available at:

    vendor/FreeTube/LICENSE

LeoTube-specific source code will live outside `vendor/FreeTube/`.
