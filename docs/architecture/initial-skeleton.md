# Initial LeoTube Skeleton

LeoTube starts as a native Cocoa/AppKit shell for Mac OS X 10.5.8 Leopard PowerPC.

## First native components

- LTAppDelegate
- LTMainWindowController
- LTInvidiousClient
- LTVideo
- LTChannel
- LTSearchResult
- LTSubscriptionStore
- LTHistoryStore

## First UI goal

A single native window with:

- sidebar
- search field
- result list
- empty detail pane

No playback in the first skeleton.
No WebKit in the first skeleton.
No FreeTube code outside vendor.
