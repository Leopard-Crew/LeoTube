# FreeTube Feature Map for LeoTube

This document maps FreeTube features to realistic LeoTube milestones.

## V0.1

- Search via Invidious
- Video detail page
- Channel detail page
- Local subscriptions
- Local history
- External player handoff
- Basic preferences

## V0.2

- Favorites / watch later
- Subscription import/export
- Thumbnail cache
- Instance selector
- Basic feed view

## V0.3

- QTKit playback experiments
- Legacy MP4 playback where available
- Better channel views
- Keyboard shortcuts

## Later

- SponsorBlock
- DeArrow
- Profiles
- Browser handoff / URL scheme
- Multi-window
- Mini player
- DASH helper
